# G-code post-processing (legacy link)

Current OrcaSlicer builds expose G-code post-processing through the
[`orca.slicing.SlicingPipelineCapabilityBase`](slicing) capability at
`orca.slicing.Step.psGCodePostProcess`. The old `orca.gcode` module and
`GCodePluginCapabilityBase` are no longer part of the current plugin API.

See [Slicing Pipeline](slicing) for the current context and example.
